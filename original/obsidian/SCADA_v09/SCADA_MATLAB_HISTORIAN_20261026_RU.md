## Допущения и ограничения
Все данные синтетические. Нет датчиков, PLC-управления, верифицированной гидравлики, сертификации Stateflow v85 либо настоящих производственных тревог. SQLite историк v04 сохраняет только выбранные времена, а не архивные все 672 отсчёта; отложенный ввод в UI не означает новое измерение. При импортированных старых job до поля SHA256 в конфигурации используется жёстко закреплённый контрольный SHA исходной v04-модели.

## 26.10.2026: безопасный запуск MATLAB по RAM
- В MATLAB LIVE добавлена проверка физически доступной памяти Windows через GlobalMemoryStatusEx: запуск нового v04 batch разрешён только при >= 6144 МБ свободной RAM; при менее 384 МБ в уже запущенном owned job срабатывает защитная остановка только этого процесса.
- HTTP negative E2E: при менее порога POST /api/run возвращает 409, число job-папок остаётся неизменным (2 до, 2 после).
- В интерфейсе HMI показывает доступную RAM, минимум 6144 МБ и блокирует кнопку нового MATLAB; headless Chrome E2E PASS, исключений JavaScript 0.
- MATLAB LIVE перезапущен после проверки владения PID, ранее завершённый v04 job восстановлен. 32/32 модульных тестов PASS.
- Ограничение: защита ресурса не заменяет успешный реальный Simulink v02 прогон, который остаётся не выполнен.
