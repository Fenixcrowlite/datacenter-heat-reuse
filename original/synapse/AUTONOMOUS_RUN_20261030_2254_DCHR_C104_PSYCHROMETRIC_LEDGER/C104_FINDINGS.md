# C104 | Психрометрический баланс бассейнового HVAC, альтернативный C102

**Статус:** вычислительный sidecar проверен; физическая валидация НЕ проведена. 2026-10-30, Bratislava. Synapse: scc-2aab24704c2bd0.

## Реальное изменение
Реализован независимый почасовой расчёт наружного воздуха для девяти сценариев C100/C102 (9×8760 = **78 840 часов**). В отличие от C102, где считалась только явная холодопроизводительность, C104 рассчитывает точку росы, насыщение, предварительную температурную рекуперацию с ограничением по точке росы, охлаждение с конденсацией, энтальпию удалённого конденсата, догрев после змеевика и остаточную осушительную нагрузку помещения.

**Важно:** C104 является **альтернативной схемой кондиционирования**, а НЕ дополнительной энергией поверх C102. C100/C102 и общая SCADA/Simulink не изменялись.

## Основные уравнения и единицы
- Влагосодержание: `w = 0.62198·p_v/(101.325-p_v)` кг/кг сухого воздуха; `p_v=RH·0.61094·exp(17.625·T/(T+243.04))` кПа.
- Энтальпия влажного воздуха: `h = 1.006·T + w·(2501+1.86·T)` кДж/кг сухого воздуха.
- Для `w_out>w_in` змеевик удаляет `m_cond = m_dry·(w_out-w_in)` кг/ч и выходит при `T_dew(w_in)`; иначе работает только явное охлаждение при `T_pre>29 °C`.
- `Q_coil = [m_dry·(h_pre-h_coil) - m_cond·4.186·T_coil]/3,600,000` МВт·ч за час. Последний член явно учитывает жидкий конденсат.
- `m_room_dehum=max(0,m_evap+m_dry·(w_coil-w_in))`, `m_humid=max(0,-m_evap-m_dry·(w_coil-w_in))`. Масса влаги замкнута; наружный конденсат НЕ оплачивается повторно комнатным осушителем.
- `E_steam=m_humid·0.75/1000` МВт·ч. Идеальный подвод к пару `m_humid·(2676-4.186·20)/3,600,000` МВт·ч является **частью** электричества парогенератора, не отдельной прибавкой.
- `E_electric=E_coil/COP3 + E_room_dehum + E_fan + E_steam`; тепловой догрев воздуха ведётся отдельно от электроэнергии. Потери испарения воды уже принадлежат водяному контуру.

## Ограничения и следующий шаг
Нет реальных T/RH, расходов воздуха, COP-кривых, bypass/frost-логики рекуператора, характеристик змеевика и оборудования. Принудительная температурная рекуперация в тёплый влажный час может повышать нагрузку охлаждения: нужна автоматика байпаса и проверка энергетически оптимального режима. C104 пока не связывает воздушный и водяной контуры через общий ограниченный источник ЦОД и не подтверждает физическую достаточность. Первичные источники: **0/31 подтверждено**.

Следующий исполнимый шаг: отдельный тестовый сценарий с bypass HRV и сравнением полных годовых балансов, затем интеграция в общий ограниченный тепловой бюджет только после согласования источников тепла и тепловых насосов.
