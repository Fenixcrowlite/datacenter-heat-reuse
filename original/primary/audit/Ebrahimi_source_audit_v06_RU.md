## Первичные наблюдения (номера печатных страниц 625–629 / PDF 4–8)
- Раздел 2.3.1: при воздушном охлаждении самая высокая температура съёма на выходе из стойки до смешения с воздухом помещения порядка 35–45 °C; на входе возврата CRAC около 30–40 °C; у возвратного потока воды чиллера около 16–18 °C.
- Раздел 3.1: жидкостное охлаждение может дать полезный уровень тепла порядка 50–60 °C; direct-use потенциал другой, чем у охлаждения воздухом 16–18 °C.
- Таблицы 5–10: диапазоны **зависят от технологического типа охлаждения**; не переносить среднюю T_source=35 °C на любой DC.
- Это обзор исследований, а не подтверждение единого почасового energy dispatch Frankfurt; параметры температур следует использовать как B-класс диапазонов по топологии, а не измерение выбранной площадки.

## Следствие для математической модели
Для heat source нельзя использовать единственный неидентифицированный scalar Tsrc_C. Требуются cooling_type, capture_location, T_in/T_out, flow и pinch для HX, с явными сценарными границами.
Формула Q=M_dot*cp*ΔT является законом сохранения энергии, а не авторской формулой этой статьи.
COP нужно выводить по конкретному рабочему циклу/карте производителя, не по температуре одного только источника.
Нельзя смешивать PUE с полезно извлекаемой тепловой мощностью.

Печатная стр. 626 / PDF стр. 5, текст: return chiller water 15.5–18.4 °C, rack exhaust 35–45 °C, CRAC return 30–40 °C.
**ВНИМАНИЕ:** Table 6 '50–60 °C / chiller 35 °C' не совпадает с диапазонами 35–45 °C / 16–18 °C из соседнего текста. Это разные литературные сценарии или несогласованное резюме, НЕ усреднять и НЕ принимать без выяснения определения точек измерения.
