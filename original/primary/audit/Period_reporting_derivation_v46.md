# Explicit period reporting and equal delivered-service comparison — v46

Engineering accounting derivation; no new primary-source equation signoff or
equipment calibration. The accepted actual Stateflow model remains v42. The
annual v13 reference retains older HP and loss-first storage assumptions; it is
used to demonstrate reporting migration, not as physical equivalence to v42.

For explicit held interval duration d_i (hours), integrate every power X_i
(MW) as E_X = sum_i X_i d_i (MWh). Timestamps mark interval starts. A saved-v42
N-sample run stops at (N-1)d and represents Nd hours, including its last executed
macro interval. A 48-hour simulation is reported as 48 hours; no annualization.
The separate annual reference executes 8760 one-hour intervals generated by the
preserved deterministic synthetic input generator.

Legacy annual schemas use HP_Heat_MW for potential output and HP_Heat_Used_MW
for actual output. An explicit adapter selects actual heat and computes direct
HP heat as actual minus charge. It requires Unmet_Heat_MW; absent shortfall is
never silently set to zero. Explicit-v45 schemas already contain actual heat.
The v45 validator then checks demand and condenser-port closure and integrates
the actual heat/work ratio for heating COP. A potential/actual factor-ten trap
and unequal durations verify this mapping without modifying the input table.

Demand closure gives E_D = E_direct + E_TESout + E_gas + E_unmet. The delivered
service is S = E_direct + E_TESout + E_gas = E_D - E_unmet. For an assumed
constant gas-boiler efficiency eta, a gas-only comparator delivering that same
S uses S/eta MWh of fuel. It is an ideal comparator sized to supply the same
delivered heat profile, not a claim that the scenario's finite backup boiler
can independently provide every interval's total delivered load.

For fuel price p_g (EUR/MWh fuel), HP electricity price p_e (EUR/MWh electric),
fuel emissions f_g and electricity emissions f_e (tCO2/MWh):

    scenario operating cost = (E_gas/eta) p_g + E_HPwork p_e
    equal-service gas baseline cost = (S/eta) p_g
    baseline minus scenario = ((S-E_gas)/eta) p_g - E_HPwork p_e
    equal-service CO2 difference = ((S-E_gas)/eta) f_g - E_HPwork f_e

Using full demand instead of S overstates the cost difference by
(E_unmet/eta) p_g, and emissions difference by (E_unmet/eta) f_g. This is an
accounting identity, not an experimental fuel saving. Shortfall is recorded
separately and creates neither nonboiler delivery nor avoided-fuel credit.
The comparison may be negative and is not clipped. Zero supplied service has
zero gas-only baseline; active charging can still incur a scenario cost.

Prices 50 EUR/MWh fuel and 100 EUR/MWh electric, efficiency 0.9 and emissions
0.202/0.20 tCO2 per respective MWh are inherited explicit demonstration
assumptions, not current Slovak prices or verified equipment values. Finite
backup limits [0,2,20] MW are scenario assumptions. HP work, including charging,
is counted once. No pump/fan/standby/network loads, CAPEX, payback, LCOH, source
attribution, ERE or standards-defined ERF are introduced. Initial TES provenance
and terminal inventory value are unpriced; unequal terminal inventory can affect
ranking. These outputs are scoped operational screening comparisons, not total
economic performance, measured validation or full-service design acceptance.

Independent QA uses rational integrated port energies and separate algebraic
service equations, and a 50-digit Decimal integrating-factor TES solution:
E(t) = exp(-kt)[E(0) + P(exp(kt)-1)/k], P = eta_c Q_c - Q_d/eta_d.
It checks segment continuity, capacity/cutoff, service and first laws, integrates
instantaneous segment ports back into macro traces, reopens original MATs and
independently follows the older v13 recurrence across all annual intervals.
Separate synthetic mutations test the reviewer; they are not actual plant
faults. Independent algorithms run within the same agent, not separate personnel.
