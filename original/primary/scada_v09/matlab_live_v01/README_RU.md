# DC HEAT | SCADA ⇄ MATLAB LIVE v01 (2026-10-24)

**STATUS: VERIFIED locally for two new Simulink executions.** Local UI: http://127.0.0.1:8094/ . Native v09 HMI: http://127.0.0.1:8091/ (navigation link "MATLAB LIVE ↗").

## Что реально происходит
1. Синтетический операторский ввод из формы проходит строгую проверку по списку численных параметров.
2. Python bridge на loopback 127.0.0.1:8094 ставит один job в запуск и передаёт конфигурацию MATLAB R2026a через локальный файл и DCHR_JOB_JSON.
3. MATLAB копирует исходный **DC_Bazen_Uzavreta_Regulacia_v04_SK.slx** в отдельную папку job, на временном экземпляре MATLAB Function адаптирует лимит бассейна, тепловой предел ТН и запрет ТН→бассейн. Исходный SLX не сохраняется и не переписывается.
4. MATLAB вызывает настоящий sim() для 672 точек с шагом 900 с (7 суток), 11 входных каналов и 25 выходов. Это v04, НЕ v08 replay и НЕ сертифицированный электрический Stateflow v85.
5. Проверяются энергетические невязки DC/ТН/бассейна/DH и дискретная динамика воды/TES; ограничение бассейна, пределы потоков, OFF условия.
6. Результаты per-run: runtime/jobs/<uuid>/config.json, копия SLX, matlab.log, result.csv и result.json. GET /api/result возвращает 672 точных рассчитанных строки для интерактивных графиков.
7. При повторном старте bridge восстанавливает последний корректный job; токен управления генерируется заново.

## Настройки из HMI
- Отключение бассейна/теплосети с заданного часа и мгновенное ON/OFF.
- Запрет догрева бассейна ТН, при сохранении возможной работы ТН на ЦО/TES.
- Предел тепла DC [0, 500] кВт; тепловой предел ТН [0, 200] кВт; предел бассейна [0, 150] кВт; лимит запроса ЦО [0, 500] кВт.
- Смещение температуры источника [-15, 20] °C относительно синтетического профиля; признаки IT, TES, HX.
- Температура обратки [5, 90] °C, расход [0.1, 100] кг/с: используются только для **производной** T_supply = T_return + Q_DH/(massflow*cp). Нет гидравлического замыкания теплосети или модели инерции труб.

## Запуск и остановка
Из этой папки PowerShell: `./start_live.ps1`; отдельно главный UI: `../start_scada.ps1`. Локальные HTTP-порты 8094 и 8091, без firewall/PLC/Docker.
Для остановки моста: `./stop_live.ps1`, он создаёт persist STOP локального моста и завершает только проверенный собственный процесс. При активной симуляции STOP должен остановить owned MATLAB job; удаление STOP автоматически запрещено. Старый главный STOP `../STOP` тоже обязателен для исполнения.

## Жёсткие ограничения
Вся модель и входы синтетические класса D. MATLAB запускается заново на каждый запрос и может быть ресурсоёмким. Результаты записаны отдельно, а архивный CSV replay и его historian в нативном HMI продолжают показывать только исходные v08, не новые v04; ссылка MATLAB LIVE ведёт в отдельную панель с независимой provenance. Блокировка иных устройств, сертификаты реальных датчиков и физический PLC отсутствуют. Ограничения теплоёмкости/климатического forcing заданы моделью, не реальными измерениями. v85 не участвует в новой задаче перераспределения.
