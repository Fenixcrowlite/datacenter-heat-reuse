# DataCenter Heat Reuse Transfer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the complete discovered project through a private repository and a verified full archive, with Python calculations, interactive diagrams and a container launch.

**Architecture:** Immutable source snapshots and a content-addressed archive preserve original work. Versioned Python model adapters produce consistent numerical records consumed by CLI and browser; every migrated algorithm retains its original revision and comparison evidence.

**Tech Stack:** Python, NumPy/SciPy where required, stdlib HTTP/SQLite, local HTML/CSS/JavaScript/SVG, Docker Compose, Git.

**Spec:** `docs/superpowers/specs/2026-10-28-transfer-design.md`, approved by user on 2026-10-28.

## Global Constraints

- Original sources and running services are not modified.
- All unique working historical algorithms belong in the migration; duplicate snapshots need one implementation with mappings.
- The graphical UI is an interactive diagram/settings/charts, without a connection editor.
- Python/container operation must not require MATLAB or author-specific absolute paths.
- Preserve SK/EN documents and all discovered project work in repository or full archive; no credentials are distributed.
- Archive replay and fresh Python computation must be visibly distinguished.
- No completeness or reproducibility claims without actual verification; unresolved model entries remain explicit.

## Review Focus

- Missing or modified archive members: extraction verifies checksums and fails with the exact affected path.
- Cross-model comparisons: compare identical inputs/revisions/time conventions, never unrelated v04 and v08.
- Nonfinite or physically invalid inputs: reject before computation and preserve the previous successful result.
- Unimplemented numerical semantics: fail closed rather than silently approximate or replay saved output as new computation.
- Fresh machine: paths, secrets, network/package availability and persistent volumes must be covered by clean-start checks.
